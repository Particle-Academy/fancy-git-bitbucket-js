# Fancy Git — Bitbucket Cloud adapter

[![Fancified](art/fancified.svg)](https://particle.academy)

Bitbucket Cloud implementation of the Fancy Git provider contract. The adapter
targets Atlassian's canonical REST/OpenAPI surface; Bitbucket Data Center is a
separate, deferred API family.
